# 单次模拟

启动 server.py，刷新主界面，配置参战角色的职业、技能组及装备，点击“开始单次模拟”。接口为 POST /api/battle/simulate-single。战斗时长来自主界面，模拟次数不影响单次模拟。

时间从0.0秒开始，每0.1秒检查一次。献祭先结算，同刻其余事件随机排序，每次行动作为完整事件执行。使用当前力速比动态判断冷却；连击固定等待0.5秒。技能组按节点跳转、顺序执行、子技能组跳转推进，末尾不跳转则停止该角色技能组。

只记录发生行动或状态变化的时刻。点击时间点查看该时刻全部事件结算后的四角色属性、生命值、buff层数和剩余时间。临时攻击增幅保留在攻击记录中，不改变持久面板。

灼烧命中后按异常附加率判定，成功时记录攻击属性并重置计时；首次伤害在1秒后，每秒一次，6秒持续时间跳6次。同名覆盖重新计算，最后一次伤害执行后到期。

装备真伤分物理和魔法；使用五乘区，无暴击、种族特攻及护甲抗性减免。旧真伤按原触发类型兼容。回复技能使用技能系数×(1+回复效果/100)×(1+辉印回复/100)，本版回复自身，封顶最大生命值。

接口可附带整数seed复现；结果展示随机种子。界面提示尚未定义的规则，包括流血/瘟疫伤害、生命值为0时的行为。本版不执行Boss主动攻击。单个队友buff缺少目标时明确报错，不猜测目标。单次模拟最长3600秒，目标被击败后结束。

测试使用临时库，不修改用户的技能、装备和技能组数据。点击展示已通过DOM交互验证，未进行浏览器截图验证。
