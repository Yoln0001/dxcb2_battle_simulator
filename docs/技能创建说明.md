# 角色技能创建

打开frontend/index.html，点击工具栏的“技能库”，通过“创建技能”填写技能定义。
技能库初始为空，不导入参考网站JSON。保存后可编辑、另存为副本、搜索、导入及导出。
关闭窗口会保留当前页面的草稿；刷新会丢失未保存草稿。切换技能或新建时提示未保存修改。

数据模型独立定义在frontend/js/skills/model.js，编辑界面在frontend/js/skills/editor.js；frontend/css/skill-editor.css控制样式。
技能库保存于浏览器的dungeon2-skill-library-v1，队伍配置仍独立保存。
跨浏览器或迁移项目应使用“导出技能库”备份；队伍导出不包含技能库。
导入采用合并，不清空原技能。同一ID相同内容去重；同一ID不同内容拒绝整次导入。

每个技能具有稳定ID、名称、职业、伤害类型、冷却秒数、命中/暴击百分数、
七项属性倍率、种族特攻和一个可选触发特效。通过验证后才允许保存和导入。

debuff：流血、瘟疫、灼烧、减速或眩晕；异常附加率、基础值、持续时间和力量/魔力/技巧/速度倍率。
异常附加率允许超过100%，原值保存，实际抵抗及概率计算后续确定。

buff：类型、触发率、基础值、持续时间、作用对象、技能类型及四行属性转化。
每行记录力量/魔力/技巧/速度/体质/血量到力量/魔力/技巧/速度之一的系数及启用开关。
未启用的行保存为零系数；enabled显式记录开关。切换特效后只保存当前选中的特效。

目前是技能定义界面，不执行战斗计算，也不把技能自动变成技能组。
技能组选取和顺序编辑将通过技能ID引用技能，独立设计。
冷却如何叠加角色速度，属性倍率如何结算，特攻增幅倍率和buff矩阵的具体算法，
以及命中后是否触发特效、增益覆盖与叠层等规则，需要确定后再接入引擎。
