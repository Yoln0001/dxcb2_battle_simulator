# 技能组
默认一个子技能组，一个技能。通过添加子技能组和添加技能按钮扩展，不设固定数量限制。
选择职业大类、转职及名称，技能从该转职的技能库中选择。
每个技能的跳转到下拉框选择子技能组及技能位置；执行该技能后进入所选节点，可跳转自身。
默认入口为子技能组1的技能1。保存前每个位置都需选择有效技能和跳转目标。
节点使用独立ID，删除节点后相关跳转清空并提示重新选择。
保存到data/skill_groups.json，schemaVersion为2，subgroups数组下skills包含{id,skillId,next}；entry为入口节点ID。
旧版两个循环技能组按原先顺序和组末跳转自动转换，旧的空循环组不显示。
接口GET/POST /api/skill-groups，PUT /api/skill-groups/{id}。校验职业匹配和跳转引用。
当前仅保存配置，尚未执行战斗。

技能跳转与组末跳转默认不跳转（空字符串），浅色显示。技能不跳转时继续本组下一技能，组末不跳转时循环本组；组末nextGroup可指向另一子技能组入口。技能单独跳转优先于组末跳转。

组末允许选择自身：跳回本组第一个技能，实现循环。组末不跳转表示结束此组执行，需明确设置自身跳转以循环；此规则取代此前隐式循环说明。
