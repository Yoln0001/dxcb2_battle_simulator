# 本地技能记录接口

在PyCharm运行项目根目录的server.py，浏览器打开 http://127.0.0.1:8000/ 。
使用FastAPI + Uvicorn。首次运行需在项目虚拟环境执行 `python -m pip install -r requirements.txt`。服务运行期间，技能库的保存按钮会把技能写入项目的data/skills.json。
第一次保存或导入时自动建立文件。服务重启后重新读取文件。
端口占用时可运行 `python server.py --port 8001`，并打开对应端口。

双击HTML依然使用浏览器本地存储。之前通过双击页面保存的技能，请先导出技能库，
再通过服务地址打开页面并导入；浏览器把这两个地址的本地数据分开存放。
HTTP页面的接口不可用时会明确报错，不会显示文件保存成功。

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | /api/skills | 读取技能库 |
| GET | /api/skills/{id} | 读取一个技能 |
| POST | /api/skills | 新增技能，缺少ID时自动生成 |
| PUT | /api/skills/{id} | 修改已有技能，保留ID |
| POST | /api/skills/import | 合并导入技能库 |

请求使用Content-Type: application/json；技能格式与“查看技能数据”一致。
新增或修改请求体是单个技能对象；导入请求体是{"schemaVersion":1,"skills":[...]}。
读取技能库返回相同技能库格式；保存返回技能库及skill字段（本次保存的技能）。
错误返回{"error":"原因"}。400表示无效数据，404表示不存在，409表示ID冲突。
参数、增益/减益和转化矩阵经过服务端校验，错误数据不写入文件。
导入存在同ID不同内容时整批拒绝；相同内容去重。文件更新采用临时文件和原子替换。
现有文件损坏时拒绝覆盖，需修复或从备份恢复。

接口仅监听本机；当前记录技能定义，不执行战斗计算。技能组仍独立设计。

接口文档：http://127.0.0.1:8000/docs ，OpenAPI格式：http://127.0.0.1:8000/openapi.json 。
后端职责：backend/app.py创建应用；backend/api/skills.py定义路由；backend/schemas/skills.py定义请求；backend/skills/store.py负责存储。
启动：python server.py；开发自动重启：python server.py --reload。JSON文件存储阶段使用单个工作进程。
